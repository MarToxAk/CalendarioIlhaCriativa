<objective>
Make the storage path S3-shaped and the background-job path durable in development, and pin the clock.

Three independent config seams:
1. **INFRA-01 (config half)** — add `aws-sdk-s3` and a `config/storage.yml` `amazon` service pointed at the MinIO endpoint (private bucket, `force_path_style: true`, bucket per env). 3. **INFRA-03** — a `config/initializers/timezone_check.rb` that raises in production and warns in development when `TZ` / `Time.zone` are not the expected Brasília values. `config.active_record.default_timezone = :local` stays (migrating to `:utc` is out of scope).

Purpose: INFRA-01 / INFRA-02 / INFRA-03. Storage and transport (plan 01) do not touch each other in code — the only shared file is the Gemfile, which is why this plan is wave 2.
