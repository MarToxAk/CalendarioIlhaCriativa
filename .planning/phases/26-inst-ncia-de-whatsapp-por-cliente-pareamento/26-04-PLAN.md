## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Admin browser → `#refresh_qr` (polling ~20s) | Único endpoint desta fase pensado para ser chamado repetidamente por um script client-side — superfície natural de abuso de custo (cada poll pode custar 1 chamada Evolution sem o throttle) |
| Admin browser → `#verify`/`#reconnect` | Ações com efeito colateral remoto real (`connect` força um novo ciclo de QR, encerrando a sessão atual do WhatsApp) — exigem clique explícito, `reconnect` tem confirmação modal no 26-05 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-26-15 | Denial of Service | Polling agressivo (ou um script externo) batendo `refresh_qr` sem limite, multiplicando chamadas ao Evolution por instância | medium | mitigate | `Rails.cache.write(..., unless_exist: true, expires_in: 15.seconds)` limita a 1 chamada real por instância a cada 15s, independente de quantos requests HTTP chegam (Task 2) |
