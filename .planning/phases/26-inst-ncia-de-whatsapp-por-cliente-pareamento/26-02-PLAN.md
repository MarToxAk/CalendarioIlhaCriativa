## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| App → host Evolution `GET /instance/fetchInstances` (adoção) | Resposta lista TODAS as instâncias do manager compartilhado, incluindo de outras apps da agência — o app só usa a entrada cujo `name`/`instanceName` bate exatamente com `livia_client_<id>`, nunca itera para agir em outra |
| App → host Evolution `POST /webhook/set/{instance}` (adoção) | Reaponta o webhook de uma instância que este app NÃO criou — ação com efeito colateral remoto real; qualquer instância cujo nome não seja `livia_client_<id>` nunca chega a este código (o `find` já filtra por nome exato) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|------------------|
| T-26-07 | Elevation of Privilege | `adopt` reapontando o webhook de uma instância de OUTRA app da agência | high | mitigate | `existing = fetch_instances.find { name == "livia_client_<id>" }` — match exato por nome namespaced; nunca adota por índice/posição nem por prefixo parcial |
| T-26-08 | Information Disclosure | Token de instância adotada (`existing["token"]`/`hash`) exposto em erro/log durante a adoção | high | mitigate | `adopt` nunca loga `existing` inteiro; o controller (`#create`/`#adopt`) só loga `e.class`, nunca o valor de `token` nem o Hash de resposta |
| T-26-09 | Tampering | `connect` (HTTP 200 + `{error:true}`) tratado como QR válido durante o fallback de adoção não-`open` | medium | mitigate | Task 1 — guard explícito `body["error"]` levanta `Transient` antes de qualquer `.dig` |
