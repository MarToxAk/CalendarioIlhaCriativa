|----------|-----------|
| Internet → Rails router | Todo tráfego não-autenticado; inclui CORS preflight OPTIONS e tentativas de brute force |
| rack-attack → API controllers | Throttle de login bloqueia brute force antes de atingir o controller |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-21-02 | Repudiation | POST /api/v1/admin/session, POST /api/v1/client/session | mitigate | Throttle rack-attack `5 req/60s/IP` adicionado em ambos os endpoints neste plano |
