# Phase 30 — UI Design Contract

> Visual and interaction contract for the **Acompanhamento ao Vivo + Hardening** surfaces:
> live per-group progress on `admin/clients/:client_id/divulgacoes/:id` (`divulgacoes#show`),
> the per-group **"Reenviar"** recovery action inside `_grupo_row`, and the per-group score
> added to each row of the divulgações history (`divulgacoes#index` + the `admin/clients#show`
> mirror). All user-facing copy is Brazilian Portuguese (pt-BR); this document's prose is
> pt-BR where it quotes on-screen text, English for tokens / paths / class names.
> Generated by gsd-ui-researcher.
>
> **This phase inherits the Phase 28 design contract verbatim**
> (`.planning/phases/28-divulga-o-agendar-sem-enviar/28-UI-SPEC.md`, which itself inherits
> Phase 26 → Phase 27). Spacing scale, the 400 / 500 / 600 typography set, the 60 / 30 / 10
> color split, the card shell, section heading, page `<h1>`, secondary button class,
> the badge-pill shape **and the canonical `divulgacao_grupos.status` → pill palette map**,
> the flash banner, the `turbo_confirm` native-dialog pattern, and the
> `divulgacao_datetime_label` helper are all **reused unchanged**. This document specifies
> only what Phase 30 *adds*: the live-updating targets, the aggregate progress line, the
> "Reenviar" button, the `error_code` / `sent_at` detail lines on `_grupo_row`, and the
> per-group score on the history list.
>
> **No new visual language.** No new hue, no new spacing token, no new font size or weight.
> Phase 30 is additive markup + real-time replacement of existing partials over the
> `solid_cable` + Turbo Streams mechanism validated in v1.5.
>
> **Out of UI scope (hardening — no surface):** the SEG-04 cross-client integration test and
> the INFRA-07 `failed_executions` retention entry in `config/recurring.yml` have **no UI**
> and are excluded from this contract.

## Spacing Scale

Inherited from Phases 26–29 (Tailwind default 4px grid). **This phase adds no new tokens.**

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px (`gap-1`) | Badge inner glyph gap (`●` → label) — unchanged |
| sm | 8px (`gap-2`, `mb-2`) | Reason line / `sent_at` line stacked under the group name inside a row |
| md | 12px (`gap-3`, `py-3`, `px-4`) | `_grupo_row` `<li>` padding (unchanged); gap between the name block, the status pill, and the "Reenviar" button |
| md+ | 16px (`mb-4`) | `_progresso_resumo` bottom margin (space between the summary line and the `<ul>` of rows) |
| lg | 24px (`p-6`) | "Grupos (N)" card interior padding (unchanged) |

**Interactive control height (inherited, ×4):** the "Reenviar" button is `h-8` (32px) — the
established compact-button height (Phase 28 "Nova divulgação" small variant, Phase 27
"Sincronizar"). It is `shrink-0` so a long group name never squeezes it.

**Row layout:** `_grupo_row` `<li>` stays `flex items-center gap-3 py-3 px-4 border-b
border-gray-100 last:border-0`. When the reason / `sent_at` lines are present the `<li>`
becomes `flex items-start` with the name block as `flex-col gap-1 min-w-0 flex-1`; the pill
and button stay top-aligned (`shrink-0`). No new spacing step — `gap-1` (4px) between the
name and its sub-line is the inherited inline-affordance gap.

**Exceptions:** none beyond those already inherited from Phases 26–29.

## Copywriting Contract

All copy pt-BR. Verbs imperative. No exclamation marks. Every datetime carries the explicit
`(BRT)` suffix via `divulgacao_datetime_label` (DIVU-05). Status labels use the DIVU-09
vocabulary exactly: `Pendente` / `Enviado` / `Falhou` / `Incerto`.

| Element | Copy |
|---------|------|
| **Primary recovery action (per-row button)** | `Reenviar` · loading label (`turbo_submits_with`): `Reenfileirando…` |
| **"Reenviar" `turbo_confirm` copy** (MUST name the group, never an id) | `Reenviar esta arte para o grupo "{dg.group_name}"? Ela pode ser postada de novo se o envio anterior tiver saído.` |
| Post-resend row note (next to the `Pendente` pill) | `· reenfileirado` |
| **Progress summary line** (`_progresso_resumo`, on `show`) | `{X} enviados · {Y} falhou · {Z} pendente · {W} incerto` — all four segments **always shown**, including zeros (makes "acabou?" legible per CONTEXT). Rendered only when the divulgação has ≥ 1 group; with 0 groups the existing `Nenhum grupo.` line stands alone. |
| Reason line — sentinel `arte_nao_aprovada` | `Motivo: a aprovação da arte foi retirada antes do envio.` |
| Reason line — sentinel `instancia_desconectada` | `Motivo: o número do cliente estava desconectado no momento do envio.` |
| Reason line — any other `error_code` | `Motivo: {dg.error_code}` — rendered **verbatim** (Phase 29 already redacted URLs and truncated to 500 chars; Phase 30 never re-sanitizes, never expands) |
| `sent_at` line (on `enviado` rows) | `Enviado em {divulgacao_datetime_label(dg.sent_at)}` → e.g. `Enviado em 15/09/2025 14:07 (BRT)` |
| **History score** (`divulgacao_placar`, 2nd line of the `Grupos` cell on `index` + mirror) | Base: `{X} enviados · {Y} falhou`. Append `· {W} incerto` only when `W > 0`; append `· {Z} pendente` only when `Z > 0`. Special cases: dispatch not started (all `pendente`) → `{N} pendentes`; divulgação with 0 groups → `—`. |
| **Resend blocked — divulgação is `cancelada`** (button not rendered; guard hit only on a stale/forged POST) | `flash[:alert]`: `Não é possível reenviar: esta divulgação foi cancelada.` — redirect back to `show`. |
| **Resend — foreign / stale group id** (`RecordNotFound`) | Standard 404 (same as `@client.divulgacoes.find`) — no custom copy. |
| **Resend — no-JS / non-Turbo fallback success** | `redirect_back fallback_location: admin_client_divulgacao_path(@client, @divulgacao)` with `flash[:notice]`: `Reenvio para o grupo "{dg.group_name}" reenfileirado.` |
| Live region | No visible "conectando…" / spinner text. The server-rendered page is already the correct initial state; `<turbo-cable-stream-source>` reconnects silently. |

**Copy notes:**
- **The only destructive action on these screens remains "Cancelar divulgação" (Phase 28).**
  "Reenviar" is a recovery action: `turbo_confirm` + neutral button styling, **no** red fill,
  **no** `_confirm_modal`. There is no new `destroy` route or button.
- The `error_code` shown on `show` is **display-only**. `divulgacao_grupo_error_label` maps the
  two known sentinels to friendly pt-BR and returns everything else unchanged — this is copy
  mapping, not re-sanitization.
- "para {n} grupos" / "{n} pendentes" are **not** pluralized against `n == 1` (consistent with
  the Phase 28 `divulgacao_duration_estimate` copy lock).

### `#resend` action — server rules (binding on the executor, not UI)

- `@client = Client.find(params[:client_id])` (or the existing `set_client`).
- `@divulgacao = @client.divulgacoes.find(params[:divulgacao_id])` → 404 cross-client.
- `@dg = @divulgacao.divulgacao_grupos.find(params[:id])` → 404 foreign group.
- Guard: `if @divulgacao.status_cancelada?` → `flash[:alert] = "Não é possível reenviar: esta
  divulgação foi cancelada."`; `redirect_to admin_client_divulgacao_path(@client, @divulgacao)`.
- `@dg.update!(status: :pendente, error_code: nil, sent_at: nil, evolution_message_id: nil)`.
- `@divulgacao.update!(status: :em_andamento) if @divulgacao.status_concluida?` — reopen so the
  badge is not "Concluída" over a `pendente` row; Phase 29 `finalize_divulgacao_if_done`
  re-closes it. **This lives in the controller, not in the Phase 29 job** (CONTEXT preference).
- `Whatsapp::SendToGroupJob.perform_later(@dg)` — the Phase 29 job, verbatim. No synchronous
  send, no Evolution call in the controller.
- Respond: `format.turbo_stream` → `resend.turbo_stream.erb` (replace `dom_id(@dg)` with
  `_grupo_row` + the "reenfileirado" note, replace `dom_id(@divulgacao, :progresso)` with
  `_progresso_resumo`). `format.html` → `redirect_back fallback_location:
  admin_client_divulgacao_path(@client, @divulgacao)` + `flash[:notice]`.

### `divulgacoes#index` + `admin/clients#show` mirror — history score

- **`#index` controller:** `@divulgacoes = @client.divulgacoes.includes(:arte,
  :divulgacao_grupos).order(scheduled_for: :desc)` then Pagy — **`includes` prevents N+1** on
  the placar.
- **Desktop table `Grupos` cell:** line 1 = total (`text-sm text-slate-700`, unchanged);
  line 2 = `<span class="text-xs text-slate-500"><%= divulgacao_placar(d) %></span>`.

- **`admin/clients#show` mirror:** the compact recent-list rows already show a status pill +

  `@divulgacoes` there must also `includes(:divulgacao_grupos)`.

### Broadcast callbacks — model rules (binding on the executor)

```
# app/models/divulgacao_grupo.rb
after_update_commit :broadcast_progresso, if: -> { saved_change_to_status? }

def broadcast_progresso
  broadcast_replace_to [divulgacao.client, divulgacao],
    target: ActionView::RecordIdentifier.dom_id(self),
    partial: "admin/divulgacoes/grupo_row", locals: { dg: self }
  broadcast_replace_to [divulgacao.client, divulgacao],
    target: ActionView::RecordIdentifier.dom_id(divulgacao, :progresso),
    partial: "admin/divulgacoes/progresso_resumo", locals: { divulgacao: divulgacao }
end

# app/models/divulgacao.rb
after_update_commit :broadcast_status, if: -> { saved_change_to_status? }

def broadcast_status
  broadcast_replace_to [client, self],
    target: ActionView::RecordIdentifier.dom_id(self, :status_badge),
    partial: "admin/divulgacoes/status_badge", locals: { divulgacao: self }
  broadcast_replace_to [client, self],
    target: ActionView::RecordIdentifier.dom_id(self, :progresso),
    partial: "admin/divulgacoes/progresso_resumo", locals: { divulgacao: self }
end
```
- Guarded by `saved_change_to_status?` — mirrors `arte.rb:27`. No broadcast on non-status
  updates (e.g. `sent_at`-only writes never happen without a status flip in Phase 29).
- `broadcast_replace_to` (high-level Turbo helper) is preferred over `approval_response.rb`'s
  manual `turbo_stream_tag` assembly for this per-record replacement.
- Stream name `[@client, @divulgacao]` must match the `turbo_stream_from` on `show` exactly.

### Helpers to add — `Admin::DivulgacoesHelper`

```
SENTINEL_ERROR_LABELS = {
  "arte_nao_aprovada"      => "Motivo: a aprovação da arte foi retirada antes do envio.",
  "instancia_desconectada" => "Motivo: o número do cliente estava desconectado no momento do envio.",
}.freeze

def divulgacao_grupo_error_label(dg)
  SENTINEL_ERROR_LABELS[dg.error_code] || "Motivo: #{dg.error_code}"
end

def divulgacao_placar(divulgacao)
  by = divulgacao.divulgacao_grupos.group_by(&:status)   # assoc already loaded via includes
  total = divulgacao.divulgacao_grupos.size
  return "—" if total.zero?
  enviado, falhou = by["enviado"].to_a.size, by["falhou"].to_a.size
  incerto, pendente = by["incerto"].to_a.size, by["pendente"].to_a.size
  return "#{pendente} pendentes" if pendente == total
  parts = ["#{enviado} enviados", "#{falhou} falhou"]
  parts << "#{incerto} incerto"  if incerto.positive?
  parts << "#{pendente} pendente" if pendente.positive?
  parts.join(" · ")
end
```
- `divulgacao_datetime_label` and `divulgacao_duration_estimate` are unchanged (Phase 28).
