<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser -> `#sync` (POST) / `#sync_status` (GET) | sessão admin autenticada; `params[:client_id]` não confiável; `#sync` muta estado + enfileira job |
| ActiveJob args (GlobalID) -> tabela `solid_queue_jobs` | argumentos de job persistem em texto no banco — nada sensível pode entrar |
| `group_sync_controller.js` (browser) -> `#sync_status` | GET same-origin sem efeito colateral |

## STRIDE Threat Register (subconjunto deste plano)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-02 | Information Disclosure | token da instância em job args / log | high | mitigate | job recebe o registro `WhatsappInstance` (GlobalID serializa classe+id); nunca `instance.token`/`instance_name`; teste asserindo token ausente de `job.serialize["arguments"]`; `Evolution::Client` loga só método/path/status/ms |
| T-27-03 | Information Disclosure | `#sync_status` enumerável cross-client | medium | mitigate | escopado por `params[:client_id]` via `Client.find`; payload só `{ syncing, synced_at, error, count }` — sem nomes/JIDs; 404 (não 403) em id cross-client herdado do `set_client` |
| T-27-05 | Tampering (CSRF) | poller GET `#sync_status` | low | accept | `sync_status` é leitura pura, sem efeito colateral — GET sem CSRF é correto; `#sync` (que muta) continua POST com CSRF de formulário Rails |
| T-27-06 | Denial of Service (auto-infligido, alimenta risco de ban) | sync-spam em `POST .../sync` | medium | mitigate | throttle Rack::Attack (6/60s por IP) + `turbo_submits_with` desabilita o botão + `Rails.cache.write(unless_exist:, expires_in: 15.seconds)` guard antes do enqueue |
| T-27-09 | Information Disclosure | `groups_sync_error` guardando string crua do upstream | low | mitigate | `mark_error` grava só códigos curtos (`transient` / `not_connected`), nunca o texto de erro do Evolution |

*Registro STRIDE completo da fase em 27-01-PLAN.md.*
